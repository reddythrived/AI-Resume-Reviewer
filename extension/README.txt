HOW TO ADD THIS CHROME EXTENSION
=================================

1. Open Chrome and go to: chrome://extensions/

2. Turn ON "Developer mode" (toggle in top-right corner).

3. Click "Load unpacked".

4. Select the "extension" folder (this folder).

5. The "AI Resume Analyzer" extension will appear. Pin it to the toolbar if you like.

6. Click the extension icon anytime to open your AI Resume Analyzer in a new tab.

Done! Your project is now in Chrome.
